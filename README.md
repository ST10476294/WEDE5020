# Sol de Janeiro - Web Development Project
## Project Overview
This project is an introductory web development school project focusing on building a multi-page, responsive website for the brand **Sol de Janeiro**. The website serves as a digital storefront and information platform, introducing users to the brand, showcasing fragrance collections, providing beauty rituals tutorials, and offering contact and stockist information.
The project was developed in two main phases:
- **Part 1:** Focused on requirements analysis, wireframing, and the development of the initial semantic HTML5 structure.
- **Part 2:** Focused on applying CSS styling, typography, colour schemes, responsive design, and improving the overall User Experience (UX) and accessibility.
## Design System
The visual design of the website is inspired by the joyful, confident, and sun-kissed culture of Brazil.
*   **Colour Palette:**
    *   Primary: Golden Yellow (`#F4B41A`)
    *   Secondary: Warm Orange (`#F58220`)
    *   Background: Soft Off-White (`#FAF9F6`)
    *   Text: Dark Grey (`#333333`)
*   **Typography:**
    *   Headings: Montserrat (sans-serif)
    *   Body: Open Sans (sans-serif)
*   **Layout:** Modern grid-based layout with a mobile-first responsive approach, utilizing CSS Flexbox.
## Project Structure
```text

│

├── fragrance.html        # Fragrance Collection & Bum Bum Cream details
```

## Technologies Used
*   **HTML5:** Semantic structuring (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
*   **CSS3:** Flexbox layout, media queries for responsiveness, custom variables (`:root`), and hover/focus states for accessibility.
## How to Run
1. Download or clone the repository to your local machine.
2. Open the project folder (`Sol de Janeiro`).
3. Double-click the `index.html` file to open it in your default web browser.
4. Use the navigation menu at the top to explore the different pages of the website. No server or build tools are required.
